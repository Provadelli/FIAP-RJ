# 🍽️ Sabor Express

O **Sabor Express** é uma aplicação desenvolvida em Python que simula o gerenciamento de restaurantes por meio de um menu interativo no terminal.
O projeto foi criado com o objetivo de praticar e consolidar conceitos fundamentais da programação, aplicando estruturas de dados, funções, condicionais, 
laços de repetição e tratamento de exceções em um sistema simples e funcional.

## ✨ Funcionalidades

- ➕ Cadastro de novos restaurantes
- 📋 Listagem de restaurantes cadastrados
- 🔄 Ativação e desativação de restaurantes
- 🖥️ Interface interativa via terminal
- ⚠️ Tratamento de entradas e opções inválidas

## 🛠️ Tecnologias Utilizadas

- Python 3
- Biblioteca padrão `os`

## 📚 Conceitos Aplicados

- Variáveis e tipos de dados
- Listas e dicionários
- Funções e modularização
- Estruturas condicionais (`if`, `elif`, `else`)
- Estruturas de repetição (`for`)
- Tratamento de exceções (`try/except`)
- Manipulação de entrada e saída de dados
- Organização e boas práticas de programação
##🎯 Objetivo

Este projeto foi desenvolvido com fins educacionais, servindo como prática dos fundamentos da linguagem Python e da lógica de programação. 
Além disso, representa parte da minha trajetória de aprendizado na área de desenvolvimento de software, buscando aprimorar habilidades de estruturação e organização de código.
