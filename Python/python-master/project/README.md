# Python Exercises

Repositório dedicado à prática de lógica de programação e ao desenvolvimento de soluções utilizando Python. Aqui estão reunidos diversos exercícios criados com o objetivo de consolidar conhecimentos, desenvolver o raciocínio lógico e fortalecer a base em programação.

## 📚 Conteúdos Abordados

- Variáveis e tipos de dados
- Entrada e saída de dados
- Operadores matemáticos e lógicos
- Estruturas condicionais (`if`, `elif`, `else`)
- Estruturas de repetição (`for` e `while`)
- Manipulação de strings
- Tratamento de erros
- Exercícios de lógica de programação

## 🎯 Objetivo

Praticar conceitos fundamentais da linguagem Python por meio da resolução de problemas e desafios, contribuindo para a evolução contínua das habilidades em desenvolvimento de software.

## 🛠️ Tecnologias Utilizadas

- Python 3
