# 🐾 Adote.me

Uma plataforma web desenvolvida para conectar pets que aguardam um lar a famílias que desejam adotar com responsabilidade e amor.

O projeto apresenta uma interface moderna, intuitiva e acessível, permitindo que usuários conheçam animais disponíveis para adoção, entendam o processo de adoção responsável e realizem um cadastro para iniciar a adoção.

---

## 📸 Demonstração

### Página Inicial
- Hero Section com chamada para adoção
- Catálogo de categorias de pets
- Pets em destaque
- Processo de adoção em 3 etapas
- Formulário completo de cadastro
- Depoimentos de adotantes
- Newsletter e rodapé institucional

## ✨ Funcionalidades

### 🐶 Catálogo de Pets

- Exibição de animais disponíveis
- Informações sobre idade
- Porte
- Localização
- Status especiais

### 📋 Cadastro para Adoção

- Nome
- E-mail
- Telefone
- Cidade e Estado
- Tipo de moradia
- Experiência prévia com pets
- Interesse de adoção
- Termo de responsabilidade

### ❤️ Processo de Adoção

1. Escolha um pet
2. Realize o cadastro
3. Agende a visita e adoção

### ⭐ Depoimentos

Seção com histórias de famílias que já adotaram através da plataforma.

---

## 🎯 Objetivos do Projeto

- Incentivar a adoção responsável
- Facilitar a conexão entre adotantes e abrigos
- Melhorar a visibilidade de animais disponíveis
- Promover conscientização sobre cuidados com pets
